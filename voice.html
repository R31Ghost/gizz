How to read the units
Hz · cycles per second
Oscillator pitch and LFO rate count repeating cycles. Filter cutoff uses Hz to mark a point in the frequency response. A 2 Hz LFO takes 500 ms per cycle.
ms · milliseconds
1,000 ms is one second. Attack, decay, release, and keyboard glide measure how long a change takes. The scope window measures how much time fits across its screen.
% · amount
Sustain is a percentage of the envelope peak. Depth and mixer levels scale signals. Output level is a percentage of its control range.
dB and signal units
Resonance in dB is a filter setting. The scope’s vertical scale shows normalized signal values. On its screen, count divisions between peaks and multiply by ms/div to find a period. Divide 1,000 by that period in ms to get Hz.

    ◉ GUIDED PATCH

    From a tone to a note

    1. Connect Oscillator Audio out → VCA Audio in → Output Audio in. Use the VCA’s Audio out for the second cable.
    2. Connect Keyboard Pitch out → Oscillator Pitch in.
    3. Connect Keyboard Gate out → ADSR Gate in and Envelope out → VCA CV in.
    4. Enable audio. Hold a key, then release it. Try a longer release and listen to how long the note takes to fade.

    ◉ UNDER THE PANEL

    Hardware and simulation

    Keyboard
    Hardware sends a pitch voltage and a separate gate voltage. With 1 V/octave, adding 1 V doubles frequency. Here, a note number sets the oscillator frequency and a held-key flag acts as the gate.
    ADSR Envelope
    In a typical analog circuit, a capacitor charges or discharges to make a changing voltage. Here, timed linear ramps rise to a peak, fall to the sustain level, then fall to zero after release.
    VCA
    A control voltage sets how much of the input signal passes through. Here, a Web Audio gain node multiplies each audio sample by the envelope, from 0 (closed) to 1 (full level).
